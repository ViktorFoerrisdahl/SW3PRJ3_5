# Kode

Her placeres ATLAS-kode, tests og hjælpeværktøjer. Der er endnu ingen systemimplementering eller vedtaget buildstruktur.

- `tools/context/generate.py`: konverterer dokumentation til fælles AI-kontekst.
- `tools/context/tests/`: regressionstests af dokumentkonverteringen.
- `tools/context/requirements.txt`: Python-afhængigheder til værktøjet.

Se [kodekonventionerne](../docs/Projektstyring/code-conventions.md) og [AI-strategien](../docs/Projektstyring/ai-strategi.md) for sprog og arbejdsform. Nye applikationsmoduler og deres tests lægges under denne mappe, når strukturen er aftalt.
